N.  Messages                                                 Command Reference

NAME
       TECH-041 (error) Layer is missing with mask name '%s'.

DESCRIPTION
       This  error message occurs when a Layer section with the specified mask
       name is missing from the technology file.  All metal and via layers  up
       to the highest defined physical layer must be defined in the technology
       file.

       For example, if only metal1, via1, metal2, via2, metal3, and metal4 are
       defined, then via3 is missing and the error message appears.

       The following is an example of the error message:

         Error : Layer is missing with mask name 'via3'. (TECH-041)

WHAT NEXT
       Define  a  Layer  section with the specified mask name and then run the
       command again.
